Generated by `bun run ios:models` from `packages/contracts`. Do not edit by hand: change the contract, run the script, and commit both. `scripts/ios/generate-swift-models.test.ts` (part of `bun run ci`) fails while these files are stale.

## Files

- One file per contract module, named after it: `catalog.ts` becomes `Catalog.swift`, `people-schemas.ts` becomes `PeopleSchemas.swift`. A type lives in the file of the module that exports its schema, or, for an anonymous schema, the module of the export or procedure it sits in.
- `Procedures.swift`: `RPC`, one descriptor per procedure (`RPC.People.positionCandidates`, `RPC.health`), `RPC.allPaths`, and `ContractErrorCode`.
- `Shared.swift`: `Nullable` and coding helpers, copied from `scripts/ios/swift-models/Shared.template.swift`.

## Names

- An exported `fooBarSchema` becomes `FooBar`. A procedure input or output with no export becomes `<Namespace><Procedure>Input` or `Output` (`HealthOutput`).
- An anonymous object or enum inside a type is the parent name plus the property (`PlanWindowHistoryBatchRequestBudget`); array items use the singular (`PlanWindowHistoryBatchPerson`). A discriminated union's payload is the union name plus the case (`ServicesAccessGranted`).
- An enum built from an exported list of values is named after the list (`SERVICES_PERMISSION_LEVELS` becomes `ServicesPermissionLevel`); `.partial()` of an export becomes `Partial<Name>`.

## Mapping

- `.optional()` is `T?` and is left out when nil. `.nullable()` is `T?` and is sent as `null` when nil. `.nullish()` in an input is `Nullable<T>?`: nil leaves the key out, `.null` sends `null`, `.value(x)` sends `x`. Decoding accepts a missing key or `null` for every optional.
- `.default(x)` is non-optional with `x` as the init default, filled in when the key is absent. Single-value literals default to their value (`success: Bool = true`).
- `z.date()` is `Date` (decode and encode with `JSONCoding`); ISO strings that the contract types as `z.string()` stay `String`. `z.number().int()` is `Int`; any other number is `Double`. `z.json()`, `z.unknown()`, and `z.any()` are `JSONValue`.
- String enums are tolerant: values this build does not know decode as `.unknown(String)` and encode back unchanged. `allCases` lists the contract's values. Discriminated unions decode an unknown discriminator as `.unknown(String)`.
- Records are dictionaries; enum-keyed ones (`EnabledFeatures`) encode as JSON objects.
- Structs are `Codable, Hashable, Sendable` (and `Identifiable` with a non-optional `id: String`), with `var` properties and a public memberwise init whose optional parameters default to nil.
